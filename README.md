## 🚀 Getting Started

### Prerequisites
- .NET 6.0 or higher (for ASP.NET Core backend)
- Node.js 14+ (for React frontend)
- Flutter SDK (for mobile app)
- PostgreSQL 12+ (for database)
- Python 3.8+ (for AI service)

### Installation

#### 1. Clone the Repository
```bash
git clone https://github.com/IT24100444/TourMate---smart-tourism-platform.git
cd TourMate---smart-tourism-platform
```

#### 2. Backend Setup (ASP.NET Core)
```bash
cd Backend
dotnet restore
dotnet appsettings.json  # Configure your database connection
dotnet ef database update  # Run migrations
dotnet run
```

#### 3. Frontend Setup (React)
```bash
cd Frontend
npm install
npm start  # Runs on http://localhost:3000
```

#### 4. Mobile Setup (Flutter)
```bash
cd Mobile
flutter pub get
flutter run
```

#### 5. AI Service Setup (Python)
```bash
cd AI-Service
pip install -r requirements.txt
python app.py
```
